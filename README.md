# Nova — Landing Page

## About the Project

Nova is a fictional productivity software brand designed to help individuals and teams organize their work, plan projects, stay focused, and track their progress.

This project is a responsive static landing page created as part of the Oasis Infobyte Web Development Internship.

## Task

**Task 1 — Landing Page**

## Technologies Used

* HTML5
* CSS3
* CSS Flexbox
* CSS Grid
* Google Fonts

## Features

* Sticky navigation bar
* Home, Features, About, and Contact navigation links
* Hero section with headline and call-to-action buttons
* Features section
* About section
* Testimonial section
* Footer with social and contact links
* Responsive design for desktop, tablet, and mobile screens
* Consistent dark and purple colour palette
* Hover effects
* Mobile-friendly layout

## Project Structure

```text
nova-landing-page/
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.

For development, the project can also be opened using the Live Server extension in Visual Studio Code.
