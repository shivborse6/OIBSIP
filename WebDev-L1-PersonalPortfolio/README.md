# Shivdarshan Borse — Personal Portfolio

## About the Project

This project is a personal portfolio website created to showcase my
skills, projects, background, and contact information.

The portfolio is designed as a digital résumé with a modern,
responsive developer-focused interface.

This project was created as part of the Oasis Infobyte Web Development
Internship.
